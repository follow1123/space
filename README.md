## 工作空间

```bash
space
├── bin # 可执行文件
├── code # 代码
├── data # 软件数据
├── docs # 文档
├── dotfiles # 配置文件
├── archives # 归档文件（压缩包、安装包）
├── personal # 私人文件（个人图片、视频、资料）
├── apps # 桌面软件
├── packages # 软件包
├── scripts # 脚本
├── tmp # 临时文件
└── README.md
```

---

`space/bin` 目录可以添加到 `PATH` 环境变量内
